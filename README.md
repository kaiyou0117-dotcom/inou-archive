# 異能スレ アーカイブ(閲覧サイト)

あにまん掲示板「ここだけ異能のある世界」の保存データ(`isou_スレ番号_スレID.json`)を、
あにまん風の見た目で読める静的サイトです。GitHub Pages でそのまま動きます。

## できること
- スレ一覧(スレ番号・開始日時・最終レス・レス数・画像数・いいね合計で並び替え、絞り込み)
- レス検索(全スレ横断。AND検索、`-語`で除外、`"…"`で完全一致、名前(コテ)検索、スレ番号の範囲指定、並び替え)
- あにまん風のスレ表示(いいね数による文字の大きさ、`>>番号` にマウスを乗せると中身を表示、返信リンク、画像)
- スレ内の絞り込み、レス番号ジャンプ、前スレ・次スレ移動、ダークモード、スマホ対応
- 保存されていないスレ番号(抜け)や、同じ番号が複数ある場合の警告を、一覧ページの上に表示

## 置き方(GitHub Desktop)
1. 新しいリポジトリを作り、このフォルダの中身をすべて入れます(`.github` と `.nojekyll` も忘れずに)。
2. 保存したスレのJSONファイルを、`data` フォルダに入れます(名前はそのまま)。
3. GitHub Desktop で commit → push します。
4. GitHub のリポジトリ画面で Settings → Pages → Branch を `main` / `(root)` にして Save。
5. 数分後、`https://ユーザー名.github.io/リポジトリ名/` で見られます。

`data` に新しいファイルを push するたびに、GitHub Actions が `data/manifest.json`(スレ一覧)を自動で作り直します。
Actions の実行が終わるまで(1分ほど)、一覧に反映されません。

## 注意
- ファイル名が `isou_数字_数字.json` の形でないもの(例: `isou_2195_7679942 (1).json`)は無視されます。
- 画像はあにまん側のURLを読み込んでいます。あにまんが終了すると、画像は表示されなくなります。
- 検索は、保存したスレをブラウザに読み込んで行います。初回は全スレの読み込みに時間がかかりますが、
  2回目以降はブラウザ内に保存されたデータを使うので速くなります。
- `noindex` を付けているので、検索エンジンには載りにくくなっています。

## 手元で試す
`node tools/build_manifest.mjs` で manifest を作り、`python -m http.server` などで開きます。
(ファイルを直接ダブルクリックして開くと、データが読めません)
